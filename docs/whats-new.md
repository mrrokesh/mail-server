# What's new

Last updated: 2026-11-26 · v0.4.0

Newest first, from [CHANGELOG.md](../CHANGELOG.md).

## 0.4.0 — 2026-11-26

Chat, masked aliases, and campaign drafts are in the product as working stubs. Enterprise can register a key reference, a SIEM destination, and a dedicated IP flag. None of those send mail or encrypt it. A partner can set the login name and logo. The colour stays the brand token.

## 0.3.0 — 2026-11-26

Drive, Docs, Meet, booking, tasks, notes, and AI writing are in the product as working stubs. Business Plus can save compliance and single sign-on settings. Two-factor sign-in can send the code with the password or on the verify step.

## 0.2.0 — 2026-11-26

MVP scaffold: control-plane API, webmail and admin screens, and the Expo mail shell. Sign-in and sign-up use the same handlers on the paths the apps already call.

## 0.1.0 — 2026-11-26

Monorepo scaffold: web, API, and mobile packages, shared error codes and design tokens, and local Postgres, Redis, and Stalwart Community.
