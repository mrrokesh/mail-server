# What you can do

Last updated: 2026-11-26 · v0.1.0

The numbered catalogue is `PROJECT_BRIEF.md` (FEATURES). Each feature gains a one-line entry here and a how-to link in the pull request that ships it. Tier tags: F Free, S Starter, B Business, BP Business Plus, E Enterprise.

| Area            | What it covers                                              | First phase |
| --------------- | ----------------------------------------------------------- | ----------- |
| Mail            | Webmail, search, aliases, rules, IMAP/SMTP on paid plans    | MVP         |
| Calendar        | Personal and shared calendars, invitations, Indian holidays | MVP         |
| Contacts        | Personal contacts and the organisation directory            | MVP         |
| Tasks and notes | Tasks, notes, and later team boards                         | v1          |
| Drive           | Files, share links, team folders                            | v1          |
| Docs            | Documents, spreadsheets, and presentations                  | v1          |
| Meet            | Video meetings                                              | v1          |
| Chat            | Channels and direct messages                                | v2          |
| Booking         | Public booking pages                                        | v1          |
| Admin           | Users, roles, audit log, policies                           | MVP         |
| Domains and DNS | Ownership check, MX, SPF, DKIM, DMARC                       | MVP         |
| Security        | MFA, passkeys, app passwords, encryption at rest            | MVP         |
| Deliverability  | SPF, DKIM, DMARC, ARC, MTA-STS                              | MVP         |

Limits for each tier are on [limits.md](./limits.md).
