# Roles and permissions

Last updated: 2026-11-26 · v0.1.0

One admin console covers security, compliance, and billing. Free tenants get owner settings only. Richer admin tools start at Starter.

| Role              | What they do                                             |
| ----------------- | -------------------------------------------------------- |
| User              | Their own mailbox, calendar, and contacts.               |
| Owner             | The tenant, including deletion and billing ownership.    |
| Billing admin     | Plans, seats, invoices, and payment methods.             |
| User admin        | Create, suspend, and delete users.                       |
| Helpdesk          | Password reset and day-to-day user support.              |
| Security admin    | MFA policy, sessions, and access policy.                 |
| Compliance admin  | Retention, hold, and export, on plans that include them. |
| Read-only         | View admin data without changing it.                     |
| Partner           | Many customer tenants, through the partner programme.    |
| Platform operator | mrrokesh.com operations and the abuse desk.              |

Operators do not get a silent view of customer mail. Access to customer data is written to an audit trail the tenant can see. Custom roles are a Business Plus feature and are not in this scaffold.
