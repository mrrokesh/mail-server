# Getting started

Last updated: 2026-11-26 · v0.1.0

Account signup, domain connection, and the first message are not available in this scaffold. The path, once those features ship, is:

1. Choose a plan (Free, Starter, Business, Business Plus, or Enterprise).
2. Add your domain and publish the DNS records from the setup wizard.
3. Create the first user.
4. Send a message from webmail or the mobile app.

Local setup for people building the product is in [local-dev.md](./local-dev.md).
